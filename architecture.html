Delivery contract

Durable first. Acknowledge second.

The consumer writes the receipt, validated event and watermark in one SQLite transaction. Kafka offset commit follows. A crash between them causes a safe replay.

What the client sees

Accepted is an explicit boundary.

Kafka mode returns HTTP 202 after broker acknowledgment. History becomes available after the worker ingests it. Invalid broker input is durably quarantined; duplicate event IDs cannot create a second accepted event.

Local mode persists directly and reports transport: local.

How the future pieces connect

Kafka → raw / cleaned Iceberg tables → Spark aggregates and Polars features, exchanged through Arrow → fault and forecasting models → FastAPI → SciPy simulation evaluation and Streamlit. Airflow coordinates repeatable lifecycle jobs; Prometheus and Grafana observe them. Helm packages application deployment; Nix supports development; Azure is optional.

SQLite journals operational events. The Iceberg REST catalog, object storage, batch transforms and model lifecycle are separate implementations. See the operations guide for verification limits.
